# 놀게더

링크 하나로 다 같이, 설치 없이 바로 시작하는 웹 파티게임. 서비스 주소: https://nolgether.com

| 게임 | 인원 |
|---|---|
| 초성 배틀 | 2명 이상 |
| 라이어 게임 | 3명 이상 (4~10명 추천) |
| 나는 누구게? | 2명 이상 (3~8명 추천) |
| 밸런스 게임 | 2명 이상 (3명 이상 추천) |
| 텔레파시 | 2명 전용 |
| 우리 얼마나 알까 | 2명 이상 (2~8명 추천) |

## 실행

```bash
npm install
npm start
```

실행하면 콘솔에 두 주소가 나옵니다.

- `http://localhost:3000`: 이 PC에서 접속
- `http://192.168.x.x:3000`: 같은 Wi-Fi에 연결된 폰에서 접속 (방 QR과 초대 링크도 이 주소로 만들어짐)

처음 실행할 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러야 폰에서 들어올 수 있습니다.

주소를 직접 정하려면 환경변수를 씁니다: `PORT=4000`, `PUBLIC_URL=https://example.com`

## 인터넷에 배포하기 (Render)

1. **GitHub에 코드 올리기**: GitHub에서 빈 저장소(예: `nolgether`)를 만들고 이 폴더를 올립니다. `node_modules`는 `.gitignore`로 빠집니다.
2. **Render 가입**: https://render.com 에서 GitHub 계정으로 가입합니다.
3. **블루프린트로 만들기**: Render 대시보드에서 **New → Blueprint**를 누르고 저장소를 고르면, `render.yaml` 설정대로 서비스가 만들어집니다.
   - 지역: 싱가포르 (한국에서 가장 가까움)
   - 플랜: 무료 (나중에 대시보드에서 유료로 변경 가능)
   - 상태 확인 주소: `/healthz`
4. 몇 분 뒤 `https://nolgether-xxxx.onrender.com` 같은 주소가 생깁니다. 초대 링크와 QR은 이 주소로 자동 생성됩니다 (Render가 알려주는 `RENDER_EXTERNAL_URL` 사용).
5. 이후 GitHub에 새 코드를 올리면 자동으로 다시 배포됩니다.

**Railway**를 쓸 때는 저장소를 연결하고 공개 도메인을 켜면 됩니다. 주소는 `RAILWAY_PUBLIC_DOMAIN`으로 자동 인식합니다.

**내 도메인을 연결하면** (예: nolgether.com) 호스팅 서비스에서 도메인을 추가하고, 환경변수 `PUBLIC_URL=https://nolgether.com`을 설정하세요.

### 알아둘 점

- **무료 플랜은 15분 동안 접속이 없으면 서버가 잠듭니다.** 다음 첫 접속이 30초~1분 정도 느립니다. 테스트에는 괜찮고, 오픈 베타 때는 유료 플랜(항상 켜짐)을 추천합니다.
- **방 정보는 서버 메모리에만 있습니다.** 재배포하거나 서버가 잠들면 열려 있던 방이 사라지니, 게임 중에는 배포하지 마세요.
- 서버는 한 대로 돌려야 합니다. 여러 대로 늘리면 같은 방 사람들이 서로 다른 서버에 붙어서 게임이 안 됩니다.
- 남용 방지: 한 IP에서 10분에 방 20개까지 만들 수 있고, 서버 전체에 방은 최대 2,000개입니다.

## 사용 흐름

1. 방장이 닉네임을 입력하고 **방 만들기**
2. 대기실의 QR, 초대 링크, 4자리 코드로 친구들이 입장 (회원가입 없음)
3. 방장이 게임과 설정을 고르고 **게임 시작**
4. 대기실의 "큰 화면 띄우기" 링크를 노트북이나 TV 브라우저로 열면 진행 화면이 크게 나옵니다 (없어도 폰만으로 진행 가능)

## 게임 규칙

**라이어 게임** (3명 이상, 4~10명 추천)
- 모두 같은 제시어를 받고, 라이어 한 명만 카테고리만 압니다. 제시어 카드는 꾹 누르고 있을 때만 보입니다.
- 순서대로 한 문장씩 설명한 뒤 투표합니다. 동표면 동표자끼리 재투표하고, 또 동표면 라이어 승리.
- 라이어가 지목되면 제시어를 맞힐 기회가 한 번 있습니다. 띄어쓰기와 대소문자는 무시하고, 방장이 판정을 바꿀 수 있습니다.
- 점수: 라이어 승리 시 라이어 +3, 시민 승리 시 라이어를 찍은 사람 +1
- 바보 모드: 라이어도 비슷한 다른 단어를 받아서 자기가 라이어인지 모릅니다.

**밸런스 게임** (2명 이상)
- 둘 중 하나를 고르고, 다수가 어느 쪽을 골랐을지 예측합니다. 맞히면 +1, 정확히 반반이면 예측한 사람 모두 +1.
- 혼자만 다른 쪽을 고르면 결과 화면에 따로 표시됩니다. 익명 설정을 켜면 누가 골랐는지 숨깁니다.

**초성 배틀** (2명 이상)
- 주제와 초성을 보고 정답을 입력합니다. 먼저 맞힌 순서대로 3·2·1점, 그 뒤로 맞히면 1점.
- 판정 순서: 입력 정리(띄어쓰기·문장부호 무시, 한글 조합 형태 통일) → 초성이 다르면 "초성이 달라요" → 정답 목록에 있으면 정답 → 초성만 맞으면 "아쉬운 답".
- 아쉬운 답은 문제가 끝난 뒤 방장이 [인정]하면 1점. 제한시간의 절반이 지나면 첫 글자 힌트. 0.4초에 한 번만 제출 가능.
- 입력창은 화면 아래에 고정되고 다시 그려지지 않아서, 다른 사람이 맞혀도 휴대폰 키보드가 닫히지 않습니다.
- 정답 데이터(`data/chosung.json`)는 `단어|허용답` 형식. 허용답에는 초성이 같은 다른 표기(맞춤법 실수, 외래어 표기)만 넣습니다.

**나는 누구게?** (2명 이상)
- 각자 단어를 받는데 내 폰에는 **다른 사람의 단어만** 보이고 내 단어는 안 보입니다. (주제를 랜덤으로 하면 내 단어의 주제만 힌트로 보여줌)
- 차례대로 "나 먹는 거야?"처럼 예/아니오 질문을 소리 내서 하고, 자기 차례에 단어를 맞힙니다. 맞히면 순서대로 탈출, 틀리면 다음 사람 차례(설정에 따라 한 번 쉬기).
- 마지막까지 남은 한 명이 벌칙 당첨. 큰 화면에는 탈출한 사람의 단어만 보여줍니다.
- 단어는 초성 배틀 데이터를 같이 쓰고, 정답 판정도 같은 방식(띄어쓰기·허용 표기)입니다.

**텔레파시** (2명 전용)
- 밸런스 질문에 둘 다 답하고, 같은 쪽을 고르면 통한 것입니다.
- 마지막에 텔레파시 지수(통한 비율)와 질문별 결과를 보여줍니다.

**우리 얼마나 알까** (2명 이상)
- 참가자가 돌아가며 주인공이 됩니다. 주인공은 자기 답을, 나머지는 주인공의 답을 고릅니다. 맞히면 +1.
- 주인공이 답하지 않은 문제는 점수 없이 넘어가고, 궁합 점수 계산에서도 빠집니다.
- 2명이면 "우리 궁합 N점", 3명 이상이면 "우리의 이해도 N%"를 보여줍니다.

## 구조

| 경로 | 내용 |
|---|---|
| `server.js` | 웹 서버, 방 관리(생성·입장·재접속·방장 위임·강퇴), 실시간 동기화 |
| `games/*.js` | 게임별 규칙과 화면에 보낼 상태 (chosung, liar, whoami, balance, telepathy, weknow) |
| `data/chosung.json` | 초성 배틀 13개 주제 246단어 |
| `data/liar.json`, `data/balance.json` | 제시어 12개 카테고리 300개, 밸런스 질문 5개 주제 82개 (텔레파시도 사용) |
| `data/weknow.json` | 우리 얼마나 알까 4개 주제 38문제 |
| `public/` | 폰 화면과 큰 화면 (한 페이지 앱) |
| `test/flow.test.js` | 가상 참가자로 여섯 게임을 끝까지 진행하는 테스트 (`npm test`) |
| `render.yaml` | Render 배포 설정 |

같은 브라우저에서 여러 참가자로 테스트하려면 주소 뒤에 `?p=2`, `?p=3`처럼 붙이면 됩니다.

방 정보는 서버 메모리에만 있어서, 서버를 다시 시작하면 열려 있던 방은 사라집니다.
